# Aptify
Aptify is a modern Gemini AI-powered interview preparation platform. It features include: 
- AI-driven interview report generation.
- Personalized preparation plans (roadmaps).
- Technical & behavioral interview questions..
- Skill gap analysis and Resume analysis with match score.
